# 🤖 Discord AI Commander

Control, edit, and deploy all your GitHub repositories directly from **Discord** on your phone using your **Google AI Pro** models!

## 📱 How to Use on Discord:

- `!repos` — List all 25+ of your GitHub repositories.
- `!repo <name> [branch]` — Choose active repo to work on (e.g., `!repo Billing-Sphere`).
- `!model` — Open interactive dropdown to pick any Google AI Pro model.
- `!status` — View active repo, branch, model, and pending changes.
- `!code <task>` — Prompt the AI to make code changes (e.g., `!code Change hero button to blue`).
- `!push` — Push changes to GitHub and trigger live Render auto-deploy.
- `!reset` — Reset session and discard changes.
